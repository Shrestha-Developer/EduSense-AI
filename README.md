# EDUSENSE-AI 🎓
**Built with Precision by Shrestha Mukherjee**

**EDUSENSE-AI** is a sophisticated analytics dashboard designed to bridge the gap between machine learning and educational insight. By leveraging predictive modeling, the application helps educators visualize student performance, assess algorithmic fairness, and simulate academic interventions in real-time.

---

## ✨ Key Features

*   **📊 Performance Analytics:** Comprehensive overview of student statistics via `StatsOverview.tsx`.
*   **⚖️ ML Fairness Tracking:** Dedicated `FairnessChart.tsx` to monitor and ensure unbiased predictive outcomes.
*   **🔮 Scenario Simulation:** A powerful `ScenarioSimulator.tsx` tool to model "what-if" academic scenarios.
*   **🤖 Prediction Engine:** Integrated `predictionService.ts` for automated student success forecasting.
*   **🧩 Modular Architecture:** A robust, type-safe component system built with React and TypeScript.

---

## 🛠️ Tech Stack

*   **Core Framework:** [React](https://reactjs.org/) (Powered by [Vite](https://vitejs.dev/))
*   **Programming Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Logic Layers:** Custom Machine Learning modules in `src/lib/ml`

---

## 🚀 Getting Started

### Prerequisites
*   **Node.js** (v18.0.0 or higher)
*   **npm** or **yarn**

### Installation

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Launch the development environment:**
    ```bash
    npm run dev
    ```

---

## 📂 Project Highlights

As seen in the project structure:
*   `src/components`: High-level UI elements (Charts, Simulators, Lists).
*   `src/lib`: The "brain" of the app, containing data structures and ML logic.
*   `src/services`: Handles the `predictionService.ts` for backend/logic integration.
*   `src/utils.ts`: Global helper functions for streamlined data processing.
